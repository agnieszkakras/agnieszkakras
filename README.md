### 📅 LapiPlan — Bilingual Family & Study Planner

**LapiPlan** is a browser-based educational planning application designed to help families organise school lessons, extracurricular activities, independent study, homework, assessments, and family time in one place. It is built in **Python with Streamlit**, backed by a local **SQLite relational database**.

**Repository:** *LapiPlan repository to be linked after publication.*

**Highlights**
- Separate study profiles with age-aware, adjustable focus-time suggestions
- Weekly schedules for lessons, extracurricular activities, and family/free-time blocks
- Overlap checks to identify conflicting weekly activities
- A rolling 10-year calendar with weekends and public-holiday rules for **Poland, the United Kingdom (regional variants), and the United States**
- School assessment planner for quizzes, tests, class exams, group projects, olympiads, presentations, and deadlines
- Study-session tracking, task completion, weekly summaries, and visual analytics
- **Polish and English** interface with a selectable visual theme
- **CSV export** and automated tests using **pytest**
- Demonstration-only **30-day trial status** and planned **PLN 14.99/month** premium model; payment processing is **not yet integrated**

**Technologies:** `Python` · `Streamlit` · `SQLite` · `SQL` · `Pandas` · `pytest` · `GitHub Actions` · `Docker`

**Engineering focus:** relational data modelling, data validation, SQL-based persistence, reporting, reusable business logic, automated testing, and clear project documentation.

> **Project status:** Locally runnable portfolio MVP. The current SQLite database and trial logic are local; a public multi-user release would require authentication, secure data isolation, privacy safeguards, and a production billing integration.
